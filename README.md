# UI Kit

Библиотека React-компонентов на TypeScript.

> 🚧 Библиотека находится в разработке. Пакет не опубликован в npm.

## Разработка

Для локального запуска проекта выполните следующие действия:

1. Убедитесь, что установлены pnpm 12.11.2 и Node.js 24.16.0 или новее в пределах 24.x

2. Клонируйте репозиторий

```sh
git clone https://github.com/danil-karnaukhov/ui-kit.git
cd ui-kit
```

3. Установите зависимости

```sh
pnpm install --frozen-lockfile
```

4. Запустите Storybook

```sh
pnpm run storybook
```
